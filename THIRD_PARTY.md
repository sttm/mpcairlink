UI 1.2.0: original physical-panel artwork generated for this project with
image_gen.imagegen from the project's AirLink concept. Unlabelled master and
prompt are in assets/airlink-physical-v1; they are not shipped as extra files.
The build bakes fixed captions/controls offline; numeric/status fields remain
native MPC widgets. The original AIRLINK wordmark and existing CC0 SVG are
used rather than generated approximations of the icon or lettering.

UI 1.2.1: the panel without baked knobs, isolated knob master and six matched
fixed-light material phases were generated with image_gen.imagegen. Masters
and prompts are in assets/airlink-physical-v2. The same six phases are scaled
for both controls; the white index is project-native raster artwork. Only
sized runtime PNGs are installed; source atlases and preview GIFs are excluded.

UI 1.2.2 knobs: original procedural mesh, materials and scene rendered offline
with Blender 3.4 / Cycles (build tool only, not linked to or shipped with the
plugin). Source script: tools/knob-render/render.py. Scene, render recipe and
65 complete positions: assets/airlink-knob-render-v1. No external models,
textures or HDRIs are used. The previously generated panel remains the base.

UI 1.2.3 experimental knob artwork: user-provided generated knob reference,
edited with OpenAI image generation to retain brushed machining and sharp
knurling while reducing directional grip lighting. Layer extraction, angular
exposure normalization, RGBA light mask and composition are project code.
Source assets: assets/airlink-layered-knob-v1; offline preview scripts are not
installed. No external HDRI, font, model or texture was introduced for these knobs.

UI 1.2.4: second imagegen edit isolates the diamond grip without smooth
reflective borders. Original edit and normalized source layers are retained
in assets/airlink-layered-knob-v2; only native-size PNG layers are installed.
The white index is composed into the grip texture using project drawing code.

UI 1.2.5: imagegen edit of the original physical panel removes the second
value recess and adds one central Output readout. Source: assets/airlink-physical-v3.
